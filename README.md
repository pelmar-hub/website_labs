Опис: Створити цільову сторінку відповідно до заданого дизайну
(Figma).
Вимоги:
● Використання семантичних тегів (<header>, <nav>, <ul>, <footer>
тощо) скрізь, де це необхідно
● Усі шрифти, колірна палітра, розміри елементів повинні суворо
відповідати дизайну.
● Pixel perfect також не є обов'язковим, АЛЕ ваш веб-сайт має
візуально відповідати шаблону дизайну (тобто, якщо елемент
горизонтально центрований на дизайні, він має виглядати центрованим
на веб-сайті)
● Усі назви класів не повинні бути безглуздими (тобто class=”myClass”)
та повинні відповідати тій самій схемі іменування, бажано BEM, але ви
можете придумати свої власні (просто будьте послідовними)
● Базова кросбраузерна підтримка (веб-сайт повинен коректно
виглядати в останніх версіях сучасних браузерів (Chrome, Safari, Edge)
● Наразі адаптивність не є обов'язковою.
P.S. Якщо ваш семестровий проект має цільовий веб-сайт, який
відповідає вимогам, ви можете пропустити цю роботу, надавши свій
веб-сайт для оцінювання.
Примітка: Вищезазначене стосується лише тих студентів, які фактично
відповідали за розробку веб-сайту. Вся команда не може скористатися
правом пропустити цю роботу!
